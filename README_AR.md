# YEMEN LIFE — حزمة البداية لمشروع Unity

هذه الحزمة هي **المرحلة الأولى من التطوير**: هيكل مشروع Unity مع مولّد أولي لمدينة يمنية بمقاس 2000×2000 متر، ومكوّنات أولية للحركة والقيادة والتبديل بين اللاعب والسيارة.

> هذه ليست لعبة مكتملة ولا ملف APK جاهزاً. يلزم فتح المشروع داخل Unity، إعداد المشهد والأصول، ثم التطوير والاختبار والبناء على جهاز Android.

## المتطلبات
- Unity Hub وإصدار Unity LTS حديث يدعم Android Build Support.
- تثبيت Android Build Support مع Android SDK & NDK Tools و OpenJDK من Unity Hub.
- إنشاء مشروع جديد من قالب **3D (Core)**، ثم نسخ مجلد `Assets/YemenLife` إلى مشروعك.

## تشغيل مولّد المدينة
1. افتح مشروع Unity.
2. أنشئ مشهداً جديداً واحفظه باسم `YemenLife`.
3. أنشئ كائناً فارغاً باسم `CityGenerator`.
4. أضف إليه السكربت `YemeniCityGenerator`.
5. من Inspector اضبط `Generate On Start` أو شغّل `GenerateCity()` من زر الاختبار داخل المحرر (يمكن إضافة زر Editor لاحقاً).
6. اضغط Play. ينشئ المولد أرضاً وشوارع ومبانٍ أولية بطابع معماري يمني مبسّط.

## إضافة أنظمة الحركة والقيادة
- أضف `CharacterController` إلى اللاعب ثم `ThirdPersonPlayer`.
- أضف `Rigidbody` و `VehicleController` إلى السيارة، مع Collider مناسب.
- أضف `VehicleInteraction` إلى اللاعب، واسحب Transform نقطة خروج السيارة إلى خانة `Exit Point` في Inspector.
- زر التفاعل يستدعى عبر `EnterOrExitVehicle()` من واجهة اللمس.

## ملاحظات مهمة
- المولد يستخدم مجسمات بدائية Placeholder؛ يجب استبدالها لاحقاً بموديلات يمنية عالية الجودة ومواد وخامات وأصوات مرخّصة.
- مساحة المدينة محددة بـ 2000×2000 متر (4 كم²)، لكن كثافة التفاصيل النهائية تحتاج إلى تقسيم العالم إلى قطاعات وتحميلها تدريجياً (World Streaming/Addressables).
- لا تستخدم أسماء أو شعارات شركات السيارات أو موديلاتها كأصول نهائية إلا مع مراعاة حقوق الملكية والترخيص.
- أنظمة المهام والشرطة والقتال والمرور والمشاة والطقس والليل والنهار لم تُنفّذ بعد؛ هي مراحل لاحقة في خطة المشروع.

## إعداد Android
1. `File > Build Settings` ثم اختر Android واضغط `Switch Platform`.
2. `Player Settings`: اجعل Package Name مثل `com.yemenlife.game`.
3. اختر ARM64، واضبط Minimum API حسب الأجهزة المستهدفة.
4. فعّل IL2CPP عند تجهيز إصدار النشر، واختبر الأداء على أجهزة فعلية.
5. `Build` لإنتاج APK تجريبي بعد اكتمال إعداد المشهد والأصول.
